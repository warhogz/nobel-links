# NOBÉL — страница с материалами, ссылками и контактами

Одна точка входа для всего, что студия даёт по ссылке или QR: презентация,
сайт, Instagram, ролики, вакансии, WhatsApp.

**Каркас** — страница для выставки: фон-шейдер, шапка, бумажный переход между
экранами, «один экран без скролла», вся механика под Safari, экраны офисов
с роликом города под статус-баром. Первый экран с текстом («FROM VISION TO
REALITY. WORLDWIDE.», Blushing Rose, слова раскрываются по одному) — оттуда же,
в точности: те же размеры и отступы.
**Дизайн-система** — основного сайта [nobeldesignstudio.com](https://nobeldesignstudio.com),
один в один: тот же файл шрифта, те же размеры, линии, стрелки, вакансии
с раскрытием в тёмную комнату. Иконок нет нигде — только стрелки основного сайта.

## Стек

- **Next.js 15** (App Router) + **React 19** + **TypeScript**
- **Tailwind 4** — токены в `src/app/globals.css`
- **Lenis** — инерционный скролл
- Статический экспорт: `npm run build` кладёт готовую папку `out/`, её отдаёт
  любой хостинг. Node на сервере не нужен.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # -> out/
```

## Шкала

Все размеры шрифта и все отступы — шаги одной шкалы (кварта, ×4/3), токены
`--s-1 … --s6` в `globals.css`. Основа — подпись под заголовком Golovinski
(`clamp(12.1px, 3.3vw, 14.4px)`), и сам заголовок уже стоит на пятом шаге
(51,5 px против 52 px на 375). Поэтому то, что оставлено как было, задаёт всё
остальное:

| Шаг | px на 375 | Что |
|---|---|---|
| `--s-1` | 9,3 | капс, номер строки |
| `--s0` | 12,4 | подписи, время, воздух внутри строки |
| `--s1` | 16,5 | строки меню «…», зазоры |
| `--s2` | 22 | имя в списке; поле страницы |
| `--s3` | 29,3 | колонка номера; отступ между блоками |
| `--s4` | 39 | название офиса; отступ перед списком |
| `--s5` | 52 | заголовок первого экрана |
| `--s6` | 69,5 | заголовок экрана (на телефоне — 17vw флагмана) |

На главной шесть строк делят оставшуюся высоту поровну: не меньше имени
с воздухом в `--s-1`, не больше чем с `--s2`. Всё сверх этого уходит в зазор
над списком, поэтому высокий телефон получает спокойный экран, а не высокие
кнопки, а SE — по-прежнему один экран.

## Чего не трогать

- `src/components/Shell.tsx` — шапка, переход, `.lift`, `.chrome-tint`. Одно
  изменение по делу: экран без «ступеньки» паркуется наверх один раз, а не
  2,5 секунды подряд — иначе длинный список вакансий утаскивало наверх из-под
  пальца. Экран офиса (с роликом) паркуется как раньше. И ещё: ссылка
  с `data-hold` не перехватывается сразу — она сначала заливается, потом сама
  просит переход событием `nobel:go`.
- Экран офиса на iPhone «закреплён» (ступенька над страницей, прилипание) —
  поэтому он обязан помещаться в один экран. Если добавлять строки, проверить
  на 375×579.
- `PaperFlow.tsx` и `.paper` — фон. Он `absolute`, а не `fixed`: в Safari
  фиксированный слой останавливается на панели браузера и оставляет полосу.
- Цвета у фиксированных элементов у краёв экрана: Safari по ним красит свои
  полосы. Поэтому у закрытой карточки «…» и у тоста фон появляется только
  когда они открыты.
- Стили `Position.module.css` — это стили основного сайта. Если вакансии там
  поменяются, файл просто копируется заново.

## Как обновлять

**Презентация.** Заменить `public/assets/NOBEL-Company-Overview.pdf` новым
файлом с тем же именем.

**Вакансии.** Массив `POSITIONS` в `config.ts` — три вакансии, у которых
есть форма в Tally, тексты дословно из `systems/vacancies/model/positions.ts`
основного сайта. `slug` — адрес для
ссылки на вакансию (`/careers/#slug`).

**Ролики.** Массив `FILMS` в `config.ts`: `id` ролика, название проекта,
подпись и превью. Превью лежат в `public/assets/yt/` — обложки самого YouTube,
обрезанные до 16:9:

```bash
curl -o thumb.jpg https://i.ytimg.com/vi/<ID>/maxresdefault.jpg
ffmpeg -i thumb.jpg -vf scale=640:360 -c:v libwebp -quality 80 public/assets/yt/<name>.webp
```

Если `maxresdefault` отдаёт 404 — взять `sddefault.jpg` (640×480 с чёрными
полосами) и обрезать: `-vf crop=640:360:0:60`.

| Ролик | Проект |
|---|---|
| `ir_L4Bc_TsY` | St. Ives, Hollywood Hills — тур Enes Yilmazer |
| `hjPmOuM_c_c` | Hidden Hills, modern barn house — тур Enes Yilmazer |
| `JEFJtnfKuIE` | Hidden Hills — интервью с Максом Нобелем (The Enes Yılmazer Podcast) |

## Публикация

Vercel: импортировать репозиторий, фреймворк Next.js, больше ничего не нужно.
`og:image` (превью в мессенджерах) Vercel сам соберёт с адресом
продакшн-деплоя; чтобы задать адрес явно — переменная `NEXT_PUBLIC_SITE_URL`.

Любой другой хостинг: `npm run build` и отдать папку `out/`.
`python scripts/serve.py` — отдать `out/` на телефон по локальной сети.

## QR-код на заставке

`/qr.html` на опубликованном сайте — внутренняя страница, в меню её нет.
Адрес подставляется сам, выбираете размер экрана телефона и тему, скачиваете
PNG. Код с максимальной коррекцией ошибок — читается под углом и с бликом.
